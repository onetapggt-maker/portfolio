# Моё портфолио

Это мой небольшой сайт, где я рассказываю о себе и своих проектах.

Сайт сделан на HTML и CSS.

## Что где находится

- `index.html` — здесь главная страница.
- `about.html` — тут я рассказываю о себе.
- `skills.html` — здесь написано, что я умею.
- `projects.html` — тут собраны мои проекты.
- `style.css` — отвечает за цвета и оформление.
- `images` — здесь лежат картинки для сайта.
- `files` — тут находятся документы для скачивания.
- `docs` — здесь лежат дополнительные заметки о проекте.

Чтобы посмотреть сайт, достаточно открыть `index.html` в браузере.
