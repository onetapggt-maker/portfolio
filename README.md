## Как устроен сайт

Обычные HTML-страницы и общий файл `style.css`. Серверная часть и установка зависимостей не нужны.
Изображения лежат в `images/`, скачиваемые документы — в `files/`.

Чтобы посмотреть сайт локально, открой `index.html` в браузере.
Можно запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.
