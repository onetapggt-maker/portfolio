VPN · Telegram · Веб

UniversalVPN

Мой VPN-сервис с Telegram-ботом и сайтом. Через них можно выбрать тариф, оплатить подписку и получить ссылку для подключения.

  • Есть пробный период, семейные тарифы, промокоды и бонусы за приглашённых друзей.
  • Оплата работает через ЮKassa и Crypto Pay. Бот напоминает, когда подписка заканчивается.
  • Для партнёров — отдельные боты, статистика продаж и заявки на выплаты.
  • Для управления сервисом — админка, проверка подключения и резервные копии базы.

Ещё делаю приложение Zenith Connect на Flutter. Пока в нём можно войти через Telegram, посмотреть подписку и открыть подключение в Happ. Подключение прямо из приложения ещё в планах.

Python · FastAPI · aiogram · PostgreSQL · Redis · Docker · Flutter

Игровой сервер

S-DDR Server

Мой сервер для DDNet / Teeworlds. За основу взят DDNet, а поверх него добавлены аккаунты, игровые монеты и новые режимы.

  • Игроки могут прокачивать уровень, переводить монеты и покупать оружие.
  • Есть дуэли со ставками в игровых монетах, блок-турниры и награды за удержание флага.
  • Добавлены кланы, VIP-функции и промокоды.
  • Через админку в браузере можно управлять игроками, делать объявления и смотреть историю действий.

C++ · CMake · Node.js · JavaScript · HTML · CSS

Идея в разработке

NEXUS

Хочу сделать сервис, в котором можно изучать связи между компаниями, людьми, технологиями и событиями. Вместо набора вкладок — карта, где видно, что с чем связано.

У каждой связи будет ссылка на источник, чтобы можно было проверить информацию. Ещё в планах — хронология событий и сравнение объектов.

Пока описал идею и то, как сервис должен работать. Самого приложения ещё нет, стек тоже пока не выбрал.
